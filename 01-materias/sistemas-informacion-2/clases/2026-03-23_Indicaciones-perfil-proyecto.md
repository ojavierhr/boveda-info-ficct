- <mark class="hltr-r">**Estructura del documento para el perfil del proyecto**</mark>
  - Seguir la estructura de títulos que dio el docente. Sin inventar, sin cambiar.
  - Normas APA obligatorias (o el formato que indique la metodología de investigación que usen).
  - **Dos carátulas**: Integrantes ordenados alfabéticamente por apellido.
    - <mark class="hltr-b">⚠️ Si no están las dos carátulas así, el docente rechaza el documento. Sin evaluación.</mark>
  - **Índice**: Navegable (enlaces activos). Mínimo 3 niveles de profundidad.
    - <mark class="hltr-b">📌 Se publicará en la plataforma, así que debe ser fácil moverse por el PDF.</mark>
  - **Introducción**: Original, escrita por ustedes. Debe responder:
    - <mark class="hltr-b">¿Qué es este documento?</mark>
    - <mark class="hltr-b">¿Por qué es importante?</mark>
    - <mark class="hltr-b">Llamar la atención del lector.</mark>
    - <mark class="hltr-b">Máximo 1 página.</mark>
  - **Antecedentes**: Resumen de la investigación previa sobre el tipo de sistema que les tocó.
    - [[2026-03-13_presentacion-materia|Clase donde se asignaron los temas]]
  - **Descripción del problema**: La parte más extensa.
    - <mark class="hltr-b">Describir con detalle, lenguaje claro y directo, los problemas que el sistema va a resolver.</mark>
    - <mark class="hltr-b">🎯 Aquí no se habla de software, solo del problema real.</mark>
  - **Objetivos del proyecto**
    - <mark class="hltr-b">Objetivo general: Una meta final clara.</mark>
    - <mark class="hltr-b"> Objetivos específicos: Pasos intermedios para llegar a esa meta.</mark>
    - <mark class="hltr-b">🔑 Todos deben empezar con un verbo (ej. “diseñar”, “implementar”, “validar”). Nada ambiguo.</mark>
  - **Alcance**: aquí sí se empieza a hablar de software.
    - <mark class="hltr-b">No se enumeran funcionalidades pequeñas.</mark>
    - <mark class="hltr-b">    - Se definen épicas, metas produccionales o módulos (ej. “Módulo de gestión de inventario”).</mark>
  - Elementos del sistema de información basado en computadora
    - <mark class="hltr-b">Hardware, software, datos, procesos, redes, actores.</mark>
    - <mark class="hltr-b">Ver el tema</mark> [[concepto-sistema-informacion-basado-computadoras|Concepto de sistema de información]].
  - **Stack tecnológico** (candidatos, pueden cambiar)

	  | **<mark class="hltr-b">Área del proyecto</mark>**			| **<mark class="hltr-b">Herramienta sugerida</mark>** 			|
	  |---------------------------------|-----------------------------------|
	  | **<mark class="hltr-b">Backend</mark>** 						| <mark class="hltr-b">Spring Boot / Django</mark> 	   			|
	  | **<mark class="hltr-b">Frontend</mark>** 						| <mark class="hltr-b">React</mark> 							|
	  | **<mark class="hltr-b">Base de datos</mark>** 					| <mark class="hltr-b">PostgreSQL</mark> 						|
	  | **<mark class="hltr-b">Desarrollo móvil</mark>** 				| <mark class="hltr-b">Flutter</mark> 							|
	  | **<mark class="hltr-b">Gestión del proyecto (Scrum)</mark>** | <mark class="hltr-b">Jira / Youtrack</mark> 					|
	  | **<mark class="hltr-b">Herramienta CASE (UML 2.5)</mark>** 		| <mark class="hltr-b">Visual Paradigm Community Edition</mark> |
	  | **<mark class="hltr-b">Control de versiones</mark >** | <mark class="hltr-b">GitHub</mark> 							|
	  
  - **Costos**
    - <mark class="hltr-b">Tabla de gastos e inversiones para el cliente.</mark>
	- <mark class="hltr-b">Dos presupuestos: **SaaS** (licencia por suscripción) y **on‑premise** (instalación local).</mark>
  - **Beneficios**
    - **<mark class="hltr-b">Cuantitativos</mark>**<mark class="hltr-b">: ahorros medibles, aumento de productividad.</mark>
    - **<mark class="hltr-b">Cualitativos</mark>**: mejor experiencia, menos errores, mayor control.
  - **Equipo de desarrollo**
    - <mark class="hltr-b">Tabla con los datos de cada integrante + sus currículums.</mark>
  - **Bibliografía**
    - <mark class="hltr-b">Referencias de tres tipos: libros, sitios web, entrevistas.</mark>
  - **Anexos**
    - <mark class="hltr-b">Todo lo que ayude a entender el problema, la solución o el desarrollo.</mark>
    - **<mark class="hltr-b">Obligatorio</mark>**:
      - <mark class="hltr-b">Formato de entrevista (tipo).</mark>
      - <mark class="hltr-b">Entrevistas realizadas.</mark>
      - <mark class="hltr-b">Documentación rescatada de las entrevistas.</mark>
      - <mark class="hltr-b">Diapositivas.</mark>
